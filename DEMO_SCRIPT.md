# Demo Script — ProofLayer

## 60-second demo

1. Open ProofLayer.
2. Enter a factual claim.
3. Click **Verify Claim**.
4. Show the loading state while the verification pipeline runs.
5. Show the verdict.
6. Point to the confidence score.
7. Show the evidence matrix/source cards.
8. Open a source URL to demonstrate traceability.

### Spoken pitch

“ProofLayer turns a web claim into an evidence-backed verification result. Instead of asking an AI to answer a claim from its memory, we collect public web evidence through our custom Bright Data Scraper Studio collector. That structured evidence is then analyzed against the claim and presented with a verdict, confidence, excerpts, and source links. The goal is simple: make AI-assisted fact checking more traceable and evidence-first.”

## Judge questions

### Why Bright Data?
Because the application needs fresh public web evidence and a reliable structured collection layer.

### What did you build?
A claim-verification pipeline connecting a web UI, API orchestration, a custom Bright Data scraper, structured evidence, and an analysis layer.

### Did you use AI?
Yes. Claude, ChatGPT, and Grok assisted development. Their use is disclosed. The team reviewed the implementation and is responsible for understanding and presenting it.

### What makes it different?
The focus is on the evidence trail: the user sees not only a verdict but also the underlying sources and evidence used to reach it.
